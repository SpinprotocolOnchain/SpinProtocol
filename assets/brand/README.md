# SPIN PROTOCOL brand assets

All assets have an opaque midnight background and remain visible after upload to GitHub or X.

| Asset | Dimensions | Use |
| --- | ---: | --- |
| `logo-mark.svg` | 1024×1024 | GitHub organization avatar, X profile image, favicon source |
| `logo-lockup.svg` | 1800×600 | README, website and presentation header |
| `github-social-preview.svg` | 1280×640 | GitHub repository social preview |
| `x-header.svg` | 1500×500 | X profile header |

Palette: Midnight `#07111F`, Mint `#42E8B1`, Cyan `#08BFEF`, Cloud `#F4F7FB`.

The segmented rings suggest a protocol round and pooled jackpot; the central core represents a settled outcome. The mark remains chain-neutral so SPIN can later support more than one ecosystem.
