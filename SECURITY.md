# Security policy

## Supported versions

`main` is the only actively maintained development version. No production contract
deployment is currently supported by this repository.

## Reporting a vulnerability

Do not report security vulnerabilities through public GitHub issues or discussions.

Use GitHub's **Private vulnerability reporting** form on this repository's Security
tab. Include a clear reproduction, affected file or contract, impact assessment and
any proof of concept needed to validate the report.

Maintainers will acknowledge a valid report, assess severity, prepare a fix privately
and coordinate disclosure after a patch is available.

## Scope

The report should identify the affected commit and whether it concerns Solidity
contracts, settlement rules, snapshot construction, RPC handling or repository
configuration. Do not test against production systems or third-party infrastructure.
